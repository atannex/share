# Atannex Share

Lets people share pages, links, text or files from a Laravel site to more than 35 networks and apps. It builds correct share links for each platform, trims text to each platform's limits, counts shares, and offers copy-link, native share, QR code and embed options. It includes ready-made Blade buttons and a share sheet, and sets the Open Graph tags that control how a link looks when shared.

## Install

```bash
composer require atannex/share
```
